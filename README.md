# 🚧 InfraCare

### Smart Infrastructure Damage Reporting & Management System

InfraCare is a smart civic-tech application that allows citizens to **report damaged public infrastructure** and helps authorities **prioritize, track, and resolve issues efficiently**.

## ✨ Features

* 📸 **Damage Reporting** – Upload images and descriptions of infrastructure damage.
* 📍 **Location Mapping** – Identify the exact location of reported issues.
* 🚦 **Severity Classification** – Categorize issues based on their urgency.
* ⚡ **Automatic Prioritization** – Prioritize critical issues first.
* 👷 **Worker Assignment** – Assign maintenance workers based on priority and location.
* 📊 **Report Tracking** – Track issues from pending to resolution.
* 🗺️ **Map Dashboard** – Monitor reported infrastructure issues geographically.

## 🛠️ Tech Stack

**Frontend:** Flutter, Dart
**Backend:** Python, FastAPI
**Database:** SQL
**APIs:** REST API
**Mapping:** Location & Map Services
**Optimization:** Google OR-Tools
**Tools:** Git, GitHub, VS Code

## 🔄 Workflow
